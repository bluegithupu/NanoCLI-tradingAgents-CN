# Goal Prompt 模板说明

本技能内置 3 类工程模板：

1. `bugfix`：缺陷修复闭环（TDD + 回归验证）
2. `feature`：单功能交付（需求冻结 + 最小实现 + 验收）
3. `release`：发布就绪闸门（质量检查 + 阻塞清单）

自动模式 `auto` 的判定关键词：

- `bugfix`: 修复、bug、报错、异常、回归、失败、错误
- `release`: 发布、上线、ready、闸门、审计、质量
- 其他默认 `feature`

每个模板统一包含：

- 目标
- 工作约束
- 执行步骤
- 完成标准

可选扩展：
- 增加“风险与阻塞登记”
- 增加“交付报告格式”
